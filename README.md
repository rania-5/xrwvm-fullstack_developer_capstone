# xrwvm-fullstack_developer_capstone

## Project Name
Best Cars Dealership - Full Stack Developer Capstone Project

## Description
A full stack web application for a national car dealership. Users can view dealerships, see reviews for each dealer, and post their own reviews after logging in.

## Technologies
- Django
- React
- Node.js and Express
- MongoDB
- Docker, Kubernetes, and IBM Cloud Code Engine
